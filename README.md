# 求职智能体

## 启动

```powershell
npm start
```

打开：

```text
http://localhost:4173/
```

## 截图识别

在“截图补录”里上传截图后，会自动 OCR 识别文字，并尝试推断状态。点击“确认识别”可以修改公司、岗位、平台、状态、日期、下一步和摘要。已归档记录也可以再次打开编辑。

截图可以作为岗位 JD、投递回执、笔试/测评、面试邀请、HR 沟通、Offer/拒信等材料归档。未确认截图先保存在 `data/短期记忆/captures`，确认后转入 `data/长期记忆/attachments`，并关联到岗位、流程时间线和材料数量。

## 自动提醒（今日总览 + 桌宠）

- **跟进/复盘**：状态为“已投递”且超过 7 天无更新的岗位，自动进入“今天先处理”并提示“已投递 N 天无反馈”，建议主动询问进度。
- **临近截止**：未完成笔试/测评的截止时间在未来 2 天内（含当天/已到期）时，置顶显示“还有 N 天”。
- **约定跟进**：`下次跟进日期` 已到或过期的岗位，提示“今天该跟进”。
- 桌宠气泡会优先提示临近截止笔试、未更新状态的笔试、待确认截图、超 7 天无反馈的岗位。

### 桌面提醒（不打开网页也能收到）

- 页面打开时：总览自动检查重要消息，浏览器通知权限开启后，消息集合变化会弹出系统通知，同时标签页标题显示 `●N` 未读标记。
- 页面关闭时：`求职提醒.ps1` 每 30 分钟（计划任务 `CareerAgentNotify30`）读取数据检查重要消息（临近截止笔试、超 7 天无反馈、待确认截图、到期跟进），有变化时弹出桌面气泡通知；相同消息不重复提醒（指纹记录在 `data/last_notify.json`）。
- 手动运行一次：`powershell -NoProfile -ExecutionPolicy Bypass -File "求职提醒.ps1"`

## 开机自启

- 注册表 Run 键 `CareerAgent` 通过 `启动隐藏.vbs` 无窗口运行 `启动求职智能体.bat`：检测 4173 端口未被占用时启动 `node server.js`，并立即执行一次桌面提醒检查。
- 取消自启：`reg delete HKCU\Software\Microsoft\Windows\CurrentVersion\Run /v CareerAgent /f`（或删除 `启动隐藏.vbs`）。

## 截图识别

“简历材料”视图自动扫描 `../简历资料` 目录（与 Excel 台账的“简历版本库”同源），按文件名归类为：简历/文案、作品集、成绩单、获奖证明、资料，并标注建议用途（如“AI应用/Agent/大模型岗位”）。材料通过 `/materials/` 只读静态服务打开，刷新按钮可重新扫描。

## 数据存储

应用现在使用服务端文件持久化，浏览器 `localStorage` 只作为临时兜底缓存：

- `data/长期记忆/state.json`：岗位、笔试、时间线、练习、牛客记录及归档项的单文件原子快照（首次启动已包含 `求职投递智能台账.xlsx` 导入的岗位与时间线数据）
- `data/长期记忆/attachments`：已确认附件
- `data/短期记忆`：待确认截图/文字补录和邮件识别结果，统一收纳在状态快照中
- `data/短期记忆/captures`：尚未确认的截图文件

旧版本的分散 JSON 文件会在首次保存时读取并迁移到状态快照，不会自动删除旧文件。可通过环境变量 `CAREER_DATA_DIR` 指定其他数据根目录。

## 邮件同步

在“邮件中心”填写：

- 邮箱地址
- 应用专用密码
- IMAP 服务器
- 端口，通常为 993
- 邮箱文件夹，通常为 INBOX
- 扫描天数

点击“同步邮件”后，系统会识别投递回执、笔试测评、面试邀请、Offer、拒信和营销推送，并按类型自动打上细分类标签：技术测试 / 性格测试 / AI面试 / 线上会议面试 / 线下面试 / 邀请投递 / 投递成功 / 简历完善邀请。智联推荐、前程无忧等平台的校招空宣、网申营销会被归为“营销推送”，不会再误判成笔试或 Offer；公司和岗位优先从邮件标题提取（【公司】、XX2027届校园招聘、XX-测试题结果通知等模式），发件人名称作为兜底。识别结果不会自动覆盖主表，需要点击“写入流程”确认；写入时同一公司的邮件会自动合并到现有岗位（不重复建岗），标签随岗位保留，岗位列表可看到各岗位的标签。

### 招聘平台关联（BOSS直聘 / 智联招聘）
- 已支持通过内置浏览器抓取 BOSS直聘、智联校园的投递状态与沟通记录：登录平台后（需在页面手动完成扫码/验证码），系统读取「网申记录」「已投递」「沟通/消息」列表，按公司写入岗位管线，来源标注 `BOSS直聘` / `智联招聘`，带「沟通中」「投递成功」等标签。
- 抓取入口：在应用内浏览器登录平台后，告知助手"抓取BOSS/智联投递记录"即可。平台登录态过期时需再次手动登录。
- 截图补录兜底：平台页面截图可走「截图补录」OCR 解析写入。
- 邮箱同步已扩为 365 天/最近 300 封（两阶段过滤：先按标题关键词筛信封、再解析正文），重同步会用最新分类结果覆盖旧记录（同 uid 覆盖），修复后重新写入不会重复建笔试记录。

笔试/测评邮件写入后，会自动新增一条笔试记录，状态默认为“未完成”，之后由你手动修改。

## 安全说明

邮箱密码只提交给本机 `localhost` 服务用于本次同步，不写入浏览器本地存储。建议使用邮箱服务商提供的应用专用密码。

## 仓库说明

本仓库**仅包含应用源码，不含任何个人数据**。`data/` 目录（含邮箱凭据 `mail-config.json`、真实投递记录 `state.json`、截图与附件等）已在 `.gitignore` 中排除，不会提交到版本库，可放心公开。

克隆后如需运行，自行在 `data/短期记忆/` 下创建 `mail-config.json`，字段示例：

```json
{
  "host": "imap.example.com",
  "port": 993,
  "user": "you@example.com",
  "password": "应用专用密码",
  "mailbox": "INBOX",
  "days": 30
}
```

`data/` 下其余目录（`长期记忆/`、`短期记忆/captures` 等）会在首次运行时自动生成。
